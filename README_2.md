# rainygold25.github.io

Source for my portfolio site: https://rainygold25.github.io

## What is here

- `index.html` is the whole site: one static page with its styles and a small script inline. There is no build step and no dependencies to install.

## Editing

1. Open `index.html` in any editor.
2. Each project is one `<article>` inside the section with `id="work"`. Copy an existing one to add a project.
3. Colors and fonts are defined once as CSS variables at the top of the `<style>` block, with a second set for dark mode.
4. Commit to `main`. GitHub Pages publishes the change within a minute or two.

## Viewing locally

Open `index.html` in a browser. No server is needed.
